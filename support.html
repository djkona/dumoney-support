두머니 고객 지원

여행과 해외생활을 위한 여러 통화 가계부입니다.

기록을 복구하려면

처음 기록할 때 연결한 이메일로 로그인하세요. 마지막 서버 백업을 자동으로 불러옵니다. 로그인 없이 사용한 기록은 별도 JSON 파일이 있어야 새 기기에서 복구할 수 있습니다.

백업 결과 확인

설정 → 클라우드 백업·복구에서 마지막 성공 시각과 서버 백업 목록을 확인하세요. 인터넷이 없거나 앱이 종료된 동안의 변경은 아직 백업되지 않았을 수 있습니다.

파일로 보관하기

설정 → 백업과 복원 → 전체 백업 파일 저장으로 JSON을 내보내세요. CSV는 엑셀 확인용이며 복원 파일은 아닙니다.

계정 삭제

설정 → 클라우드 백업·복구 → 계정 삭제에서 새 이메일 코드와 ‘계정 삭제’ 문구를 입력하고 최종 확인합니다. 계정과 서버 백업은 영구 삭제되며 기기 기록과 직접 내보낸 파일은 별도 관리합니다.

문의 전 확인

앱 버전, 휴대폰 OS, 오류 문구를 적어 문의해 주세요. 비밀번호·인증 코드·API 키는 보내지 마세요. 장부 파일은 필요한 경우에만 안전한 경로로 공유하세요.
